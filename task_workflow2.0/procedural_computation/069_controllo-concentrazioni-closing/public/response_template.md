# Formato della risposta

Produci i seguenti file:

- `merger_control_timeline.md`

Il file Markdown principale non deve superare 3.200 parole. Usa, nell'ordine, queste sezioni:

1. Esito soglie
2. Calendario filing
3. Closing condition
4. Richieste informative
5. Long-stop
6. Condotta interim
7. Punti aperti

Per ogni issue indica conclusione, documento, conseguenza e azione. Le date devono mostrare il calcolo. Le revisioni DOCX, quando richieste, devono essere revisioni tracciate reali e la nota deve restare leggibile senza aprire il binario.

Per ogni data o importo calcolato indica in una riga separata dato iniziale, regola di computo, operazione e risultato; se il dies a quo manca, non sostituirlo con una data diversa.
