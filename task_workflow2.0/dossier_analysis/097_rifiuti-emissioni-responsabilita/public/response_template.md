# WF2-097 - Struttura della risposta

Consegna `environmental_compliance_memo.md`.

Limite: 3200 parole.

Sezioni, in questo ordine:

1. Stato alla data di riferimento
2. Cronologia verificata
3. Che cosa è contestato
4. Che cosa non è contestato ed è comunque un problema
5. Esposizione della società e delle persone
6. Posizione di gestore
7. Scadenze calcolate
8. Elementi verificati e privi di rilievo
9. Elementi che il fascicolo non consente di fissare
10. Azioni
11. Decisioni del committente

Il file `environmental_compliance_memo.md` contiene le sezioni elencate sopra.
Ogni scadenza indica l'evento di decorrenza, il calcolo e la data.
Ogni voce indica il documento del fascicolo da cui i dati provengono.
Nessun riferimento normativo fuori dall'elenco chiuso del reference pack.
