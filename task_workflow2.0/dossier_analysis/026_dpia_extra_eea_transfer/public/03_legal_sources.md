# Fonti legali e freeze normativo

Le fonti sono state verificate il 25 agosto 2026. Anche quando i fatti del caso hanno data
successiva, si applicano esclusivamente il reference pack e le fonti qui elencate nello stato
vigente a tale data. Non vanno ipotizzate
modifiche legislative, nuove decisioni di adeguatezza o aggiornamenti di prassi successivi.

- [Regolamento (UE) 2016/679](https://eur-lex.europa.eu/eli/reg/2016/679/oj/ita)
- [Decisione di esecuzione (UE) 2021/914](https://eur-lex.europa.eu/eli/dec_impl/2021/914/oj/ita)
- [Decisioni di adeguatezza della Commissione](https://commission.europa.eu/law/law-topic/data-protection/international-dimension-data-protection/adequacy-decisions_en)
- [Raccomandazioni EDPB 01/2020](https://www.edpb.europa.eu/our-work-tools/our-documents/recommendations/recommendations-012020-measures-supplement-transfer_en)
