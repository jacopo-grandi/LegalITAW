# WF2-073 - Distractor

## Risposta intenzionalmente difettosa

La risposta prende per affidabile la posizione di parte contenuta nell'ultimo allegato, omette le fonti primarie e non distingue le lacune dai fatti. Propone quindi di chiudere il fascicolo senza ulteriori verifiche.
