## File 1 — `contratto_redline.docx`

La bozza del documento 01 con le modifiche apportate **come revisioni tracciate**, non come testo
riscritto: le parti soppresse devono restare visibili come cancellazioni e le parti aggiunte come
inserimenti, con autore e data della revisione.

Le revisioni devono riguardare esclusivamente gli articoli e le definizioni che ricadono nel perimetro
indicato nell'incarico. Nessuna revisione negli articoli esclusi.
