# WF2-091 - Struttura della risposta

Consegna `clean_team_protocol_redline.docx + note.md`.

Limite: 3000 parole.

Sezioni, in questo ordine:

1. Interventi da eseguire subito, indipendenti dalla revisione del testo
2. Interventi sulla bozza di protocollo
3. Richieste informative da correggere fuori dal testo
4. Posizione minima per ciascun intervento
5. Elementi che non richiedono intervento
6. Lacune documentali e istruzioni richieste
7. Risposta al direttore generale sulla riunione del 16 ottobre

Il file `clean_team_protocol_redline.docx` contiene la bozza con le modifiche tracciate.
Il file `note.md` contiene le sezioni elencate sopra.
Ogni intervento della nota indica la clausola su cui incide, almeno un allegato del fascicolo e la posizione minima proposta.
Nessun riferimento normativo fuori dall'elenco chiuso del reference pack.
