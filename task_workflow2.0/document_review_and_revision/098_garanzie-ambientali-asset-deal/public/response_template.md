# WF2-098 - Struttura della risposta

Consegna `environmental_schedule_redline.docx + note.md`.

Limite: 2600 parole.

Sezioni, in questo ordine:

1. Quadratura economica
2. Interventi sul testo, in ordine di priorità
3. Interventi da eseguire fuori dal testo
4. Posizione minima per ciascun intervento
5. Elementi che non richiedono intervento
6. Risposta alle osservazioni dell'amministratore delegato
7. Lacune documentali e decisioni richieste

Il file `environmental_schedule_redline.docx` contiene la bozza dell'Allegato 7 con le modifiche tracciate.
Il file `note.md` contiene le sezioni elencate sopra.
Ogni intervento della nota indica la clausola su cui incide, almeno un allegato del fascicolo e la posizione minima proposta.
Nessun riferimento normativo fuori dall'elenco chiuso del reference pack.
