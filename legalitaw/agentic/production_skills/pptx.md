# PPTX

Use an installed presentation library when available. Establish a consistent
slide size, grid, typography, and restrained palette. Keep each slide focused
on one point and use speaker notes only when the task calls for them. Save the
final deck under `output/`, reopen it, verify slide count and extracted text,
and inspect the OOXML package for corruption. If rendering tools are available,
render every slide and visually check clipping, overflow, and contrast.
